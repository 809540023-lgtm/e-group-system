# 12_marketing_content 行銷素材與廣告草稿中心

任務目標：行銷素材與廣告草稿中心

依賴：05_catalog_pricing, 06_storefront

閱讀規劃書章節：12, 13

可改檔案範圍：apps/web/src/app/admin/, packages/domain/marketing/, packages/db/, apps/worker/, test/marketing/, docs/handoffs/

建 creative、campaign draft、素材版本、來源證據、圖片權利、平臺用途與審核狀態。從核准商品產生 FB/IG 圖文、Reels 指令碼、LINE 商品訊息與 ChatGPT 廣告草稿。素材與特定商品版次連線，售價、效期、庫存、到貨條件變動標記需更新。

母版使用真實商品圖，商品內容只引用核准來源。食品與保健內容不可自創醫療宣稱；日本標示轉臺灣文案經品類核對。文案包含商品、規格、價格、條件與行動，適合大字閱讀。每個落地頁與廣告承諾一致。

建立通用 UTM、素材預覽、人工編輯、審核、排程及 feed 匯出。驗收錯版本、已下架商品、過期優惠、缺圖、來源不明與不可用功效說明。只形成內容中心，不把一般發文 API 和付費投放 API 混為一個成功狀態。
